# Source Validation

검증일: 2026-06-01

이 프로젝트의 신뢰 정보와 AI 상담 지식은 정부·공공기관 자료와 산부인과 전문기관 자료만 사용합니다. 진단, 처방, 복용 결정, 응급 판단은 앱이 대신하지 않고 의료진 상담으로 안내합니다.

## 사용 출처

| 카테고리 | 출처 | 사용 이유 |
| --- | --- | --- |
| 영양 | 질병관리청 국가건강정보포털 | 국내 공공 건강정보 포털의 임산부 식이영양 자료 |
| 영양 | 미국산부인과학회(ACOG) | 산부인과 전문기관의 임신 중 건강한 식사 자료 |

| 태아발달 | 미국산부인과학회(ACOG) | 산부인과 전문기관의 주수별 태아 발달 자료 |
| 수면 | 미국산부인과학회(ACOG) | 산부인과 전문기관의 임신 중 수면 자세 자료 |

## 적용 원칙

- 정부·공공기관 또는 산부인과 전문기관 출처가 없는 내용은 신뢰 정보 화면에 넣지 않습니다.
- 원문을 그대로 복사하지 않고, 앱 사용자에게 필요한 문장으로 요약합니다.
- 위험 신호는 “정보 제공”이 아니라 “의료기관 연락”으로 안내합니다.
- 영양제, 약, 운동 강도, 진단명, 치료 판단은 담당 산부인과 확인을 우선합니다.

## 배포 전 확인

- 원문 링크가 열리는지 확인합니다.
- 실제 서비스 배포 전 의료진 또는 의료 콘텐츠 책임자의 문구 검토를 받습니다.
- 응급 증상, 자해·타해 생각, 태동 감소 등은 앱 상담보다 즉시 연락 안내가 먼저 나오도록 테스트합니다.
